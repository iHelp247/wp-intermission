Getting started (two minutes)

Install and activate the plugin, then open Settings → WP Intermission. Tick Enabled and press Save Changes. That's it — visitors now see a polished maintenance page, while you (and anyone who can edit content) still see the normal site, with a red MAINTENANCE ON badge in the admin bar so nobody forgets.

Because logged-in editors always see the live site, check your maintenance page in a private/incognito window — that's what visitors get.

Response code — which one?

503 for short maintenance (hours or days): search engines understand it's temporary and change nothing. 200 for an extended coming-soon page that should behave like a normal page. When unsure, 503.

Designer — build the page without code

Designer is the default page source: simple fields on the left, a live preview on the right, rendered inside a monitor, laptop, or phone at true scale — what you see is what visitors get. Nothing changes on the live site until you press Save Changes.

Background

Pick an image from the Media Library, or choose a style: the stock dark gradient, a solid color, or a two-color gradient. The Glass effect checkbox adds the dark overlay and blur that make text readable over photos — turn it off for light designs.

Text

Title, subtitle, and main text each have their own size and color. {{SITE_NAME}} in any field becomes your site's name automatically; {{YEAR}} becomes the current year. Leave the subtitle empty to hide it.

Fonts

The title and the body text each get their own font, three ways: System (native look, fastest, zero external calls — pick a style from the dropdown), Google Font (start typing a name and pick from suggestions shown in their real face; note visitors' browsers will contact Google, which matters under GDPR), or Self-hosted (upload a .woff2 file through the Media Library — right for licensed or custom brand fonts; nothing leaves your server).

Disclaimer

Optional footer legal text. The Insert standard no-collection wording button adds vetted language for a page that collects nothing — edit it freely, and have counsel review anything site-specific.

Countdown & launching

Tick Enable countdown and set a target date and time (your site's timezone). Designer shows the timer automatically; in the other modes, put {ihelp-wp-countdown} wherever you want it. Unticking the checkbox hides the timer without losing your date. Style it with the shape (squares, rounded, circles), digit color, and its own font — digital-looking faces such as Orbitron, VT323, or Share Tech Mono suit it well, and the monospace system option guarantees rock-steady digits.

At zero, choose what happens: keep showing 00s, hide the countdown, or take the site live — maintenance mode switches itself off at T-0 and visitors watching the countdown refresh into the live site. The settings page warns you in red if you pick "take the site live" with a date that's already in the past (saving would end maintenance immediately).

Bold and italics: type <strong> or <em> around words in any text field. New lines in the main text and disclaimer become line breaks automatically. Note that Google or self-hosted fonts load in one weight — browsers simulate bold/italic for them, which looks fine for a word or two; system fonts use their true bold and italic faces.

Advanced (for power users — safely ignorable)

Other page sources

Styled template + content editor: edit just the content with the WordPress editor inside the stock design. Full custom HTML: paste a complete HTML document and it's served byte-for-byte — your styles, your everything. Tokens work in all modes.

Core-update coverage

While WordPress updates itself, plugins can't run — WordPress shows a plain "Briefly unavailable" text instead. Tick this and the plugin generates wp-content/maintenance.php, a snapshot of your page that WordPress serves during those windows. It regenerates on every save and is removed if you deactivate the plugin.

Database-failure coverage

Same idea for the "Error establishing a database connection" screen: your branded page (with a 503) instead of the bare error. Leave it off in development environments where you want raw errors visible.

The corner credit

The served page carries a small "intermission by iHelp247" link in the bottom-right corner. Don't want it? Tick the checkbox at the bottom of the settings page and it's gone — free either way; the link just helps others find the plugin. And if WP Intermission is earning its keep, the buttons next to that checkbox are how you tell us to keep building: a review, or an energy drink — any amount, one-time or monthly, chosen at checkout (opens in a new tab), straight to feeding the developers' break room.

Force overwrite (foreign files)

If another tool owns wp-content/maintenance.php or db-error.php and you can't remove it, the Force overwrite checkbox (inside the Core-update coverage section) replaces those files when you save — with a snapshot of your designed page, never a generic screen — and it switches core-update coverage on for you. Treat it as unreliable: the file is only checked and replaced at save time — it is not monitored, and the other tool can put its copy back whenever it likes. One owner per site is still the clean fix.

Self-diagnosis — when something looks wrong

"I enabled it, but I still see my normal site."

Working as designed — logged-in editors always see the live site. Open a private/incognito window, or use the Preview link on the settings page.

"Visitors still see the old page after I saved changes."

A cache is serving the old copy. If you use Cloudflare or a caching plugin, purge it. The plugin itself sends no-cache headers, so once purged it stays fresh.

"The core-update checkbox is blocked with a red message."

Another tool (often a hosting control panel's maintenance feature) owns wp-content/maintenance.php. This plugin doesn't overwrite other tools' files by default. Turn the other maintenance feature off, delete that file, and save again — or tick Force overwrite in the Core-update coverage section (see Advanced), accepting that the other tool can recreate its file at any time. Note: some tools leave the file in place even when their maintenance is off.

"My Google Font isn't applying."

The family name must match exactly. Use the suggestion dropdown — type two letters and click the name rendered in its real face. If a rare font isn't in the suggestions, copy the exact name from fonts.google.com.

"The countdown hit zero but the site didn't go live."

The countdown is display-only unless At zero is set to take the site live on the settings page.

"The preview looks different from the live page."

The preview shows unsaved edits; the live page shows the last save. If they differ, you probably haven't saved yet.

"Something went wrong — will my site white-screen?"

No. The plugin fails open: if its page can't be built for any reason, it steps aside and your normal site serves. Maintenance mode can never take your site down.

Still stuck?

Open an issue on the GitHub repository. For security concerns, use the repository's private vulnerability reporting instead of a public issue.

Removing the plugin

Deactivate stops everything and removes any generated maintenance.php / db-error.php files. Delete additionally removes all saved settings. Your uploaded media stays in the Media Library — it's yours.
